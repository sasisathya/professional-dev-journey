## 💡 Study Tips

### Daily Routine

**Morning (1.5 hours)**
1. Node.js (30 min) - Focus on event loop/async
2. JavaScript (30 min) - Language fundamentals
3. React (30 min) - State & effects

**Mid-Day (1.5 hours)**
4. Java (30 min) - OOP & principles
5. Spring Boot (30 min) - Framework patterns
6. DevOps (30 min) - Deployment & infrastructure

**Afternoon (1.5 hours)**
7. GCP (30 min) - Cloud platform
8. System Design (30 min) - Architecture
9. DSA (30 min) - Algorithms & data structures

### Study Strategies

1. **Active Reading**
   - Take notes on key concepts
   - Pause and think about examples
   - Write definitions in your own words

2. **Coding Along**
   - Type out code examples
   - Run them locally
   - Modify and experiment

3. **Spaced Repetition**
   - Review difficult concepts multiple times
   - Test yourself with Q&A
   - Return to weak areas

4. **Teaching Others**
   - Explain concepts to someone
   - Write your own summaries
   - Create flashcards

5. **Daily Review**
   - 15-minute recap before sleep
   - Review 3 hardest concepts
   - Plan next day

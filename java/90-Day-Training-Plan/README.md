## How to Use This

### 1. **Daily Routine**
Every day:
1. Copy `DAILY-LOG-TEMPLATE.md` → `Week-XX/Day-XX.md`
2. Fill in your progress as you learn
3. Answer the 10 daily questions (will be provided)
4. Solve 2 DSA problems (update `DSA-TRACKER.md`)
5. Work on current project (update `PROJECTS-TRACKER.md`)
6. Log hours and energy levels

### 2. **Weekly Review**
Every Sunday:
- Review the week's progress
- Complete weekly assessment (20 questions)
- Plan next week's focus areas
- Update trackers

### 3. **Git Commits**
Commit daily:
```bash
git add .
git commit -m "Day X: Completed [topics] - [X] hours logged"
git push
```

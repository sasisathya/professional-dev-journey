# Week 1: Java Advanced - OOP & Design Patterns
**Dates:** Day 1-7
**Focus:** Deep dive into advanced Java concepts

---

## Learning Objectives

By end of Week 1, you should master:
1. Advanced OOP principles (Abstraction, Encapsulation, Inheritance, Polymorphism)
2. SOLID principles in practice
3. 5 Core Design Patterns (Singleton, Factory, Builder, Observer, Strategy)
4. Interface vs Abstract class - when to use what
5. Exception handling best practices

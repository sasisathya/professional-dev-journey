## Learning Path by Experience Level

### WEEK 1-2: Foundations Only
- [ ] Read: Sections on Arrays, Hash Tables, Sorting in patterns-reference.md
- [ ] Read: main.md for context
- [ ] Practice: LeetCode problems on arrays and hashing
- [ ] Goal: Understand why sorting matters, when hashing is useful

### WEEK 3-4: Core Techniques (The Big Three)
- [ ] Study: Two Pointers, Binary Search, Sliding Window
- [ ] Read: patterns-quick-ref.md for quick lookup
- [ ] Practice: 10 problems each pattern
- [ ] Implement: Code templates from memory
- [ ] Goal: These three patterns solve 70% of medium problems

### WEEK 5-6: Data Structures Deep Dive
- [ ] Study: Stack, Queue, Heap, Hash Map advanced uses
- [ ] Practice: 8-10 problems per data structure
- [ ] Understand: Trade-offs between alternatives
- [ ] Goal: Know which DS for which problem type

### WEEK 7-10: Trees & Graphs
- [ ] Study: Tree traversal (DFS/BFS), BST, Graph algorithms
- [ ] Practice: 15+ tree problems, 15+ graph problems
- [ ] Understand: Recursion deeply, graph representation
- [ ] Goal: Be confident with tree/graph problem types

### WEEK 11-14: Advanced Patterns
- [ ] Study: Dynamic Programming, Backtracking, Greedy
- [ ] Practice: 20 DP problems, 10 backtracking, 10 greedy
- [ ] Understand: When to use each approach
- [ ] Goal: Complete LeetCode medium section

### WEEK 15-16: Specialization & Weak Spots
- [ ] Identify: Which patterns you're weakest at
- [ ] Study: Bit manipulation, Monotonic stack, Trie
- [ ] Practice: Mock interviews
- [ ] Goal: Prepare for actual interviews

## How to Use These Files

### For Daily Study
1. Open **patterns-quick-ref.md**
2. Find your problem type in the index
3. Read the pattern description
4. Look up the full pattern in **patterns-reference.md**
5. Code template available in quick-ref
6. Solve problem, compare complexity

### For Deep Learning of One Pattern
1. Go to **patterns-reference.md**
2. Find the pattern section
3. Understand the category, use cases, complexity
4. Review all LeetCode examples mentioned
5. Solve each example, understand variations
6. Check **two-sum.md** as example of deep pattern study

### For Interview Preparation
1. Print or bookmark **patterns-quick-ref.md**
2. Do mock interviews
3. After each problem: Check quick-ref for pattern confirmation
4. Track weak patterns
5. Focus last 2 weeks on weak patterns
6. Practice speed coding from templates

### For Teaching / Explaining
1. Use the visual dependency tree in **patterns-quick-ref.md**
2. Explain why patterns are learned in sequence
3. Use real-world applications from **patterns-reference.md**
4. Show complexity comparisons from tables
5. Use pro tips section for best practices

# DSA 16-Week Study Schedule

> Complete learning path from foundations to interview-ready

---

## Overview

- **Total Duration:** 16 weeks
- **Study Pace:** 5 hours/day, 6 days/week
- **Total Hours:** ~480 hours
- **Phases:** 5 phases, each 3-4 weeks

## Daily Routine

### Typical 5-Hour Day

**1. Warm-up (30 min)**
- Review previous day's problems
- Look up one pattern's complexity table

**2. New Pattern Learning (45 min)**
- Read pattern concept
- Understand when to use
- Review code templates

**3. Problem Solving (2 hours)**
- Solve 2-3 problems from pattern
- Code from scratch (no copy-paste)
- Analyze complexity after solving

**4. Advanced Problem (1 hour)**
- Solve 1 harder problem
- Try to optimize
- Review editorial

**5. Review & Reflect (30 min)**
- Note key insights
- Identify similar patterns
- Plan tomorrow's focus

## Success Milestones

- **End of Week 2:** Can solve all Two Pointer / Array / Hashing problems confidently
- **End of Week 4:** Sliding Window + Binary Search are muscle memory
- **End of Week 6:** Trees and basic recursion understood
- **End of Week 8:** Graph problems feel natural
- **End of Week 12:** Can solve most LeetCode medium problems
- **End of Week 16:** Consistently solving hard problems in under 45 min

---

## Adjustment Tips

**If falling behind:**
- Focus on pattern foundation only
- Skip advanced variants temporarily
- Do 10 problems of weak pattern before moving on

**If ahead of schedule:**
- Dive deeper into advanced patterns
- Start doing mixed practice (2 patterns per day)
- Solve more hard problems

**If struggling:**
- Extend phase duration by 1 week
- Review 2-3 problems daily from weak patterns
- Don't move forward until 80%+ accuracy

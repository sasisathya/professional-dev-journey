## 💡 Pro Tips

**Learning:**
- Solve same-type problems 2-3 times to solidify pattern
- Explain each solution to imaginary person while coding
- Write down insights after each problem
- Don't move until 80%+ accuracy on current pattern

**Speed:**
- Time yourself starting week 3
- Target: Easy 20 min, Medium 30 min, Hard 40 min
- Practice speed drills (5 easy in 50 min)
- Track your time progress weekly

**Weak Areas:**
- Identify by end of week 2
- Spend extra time on those patterns
- Do 5+ problems per sub-pattern if struggling
- Review concept again before each problem

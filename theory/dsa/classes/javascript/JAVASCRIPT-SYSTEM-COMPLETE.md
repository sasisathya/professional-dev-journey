## 🔄 Porting from Java to JavaScript

### Equivalencies:

| Java | JavaScript |
|------|------------|
| `HashMap<K, V>` | `Map` or Object `{}` |
| `ArrayList<T>` | `Array` or `[]` |
| `Stack<T>` | `Array` with `.push()/.pop()` |
| `Queue<T>` | `Array` with `.shift()/.push()` |
| `Set<T>` | `Set` |
| `PriorityQueue<T>` | Custom or use heap library |
| `class Node {...}` | `class Node {...}` or objects |
| `int[]` | `Array` or `Uint32Array` |

### Example Port:
```java
// Java
HashMap<String, Integer> map = new HashMap<>();
map.put("key", 1);
if (map.containsKey("key")) { ... }
```

```javascript
// JavaScript
const map = new Map();
map.set("key", 1);
if (map.has("key")) { ... }
```

## 🎯 Key Differences: Java vs JavaScript

### Memory Management:
- **Java**: Manual or GC-managed; typed arrays
- **JS**: GC always; dynamic typing

### Data Structures:
- **Java**: Rich built-in collections
- **JS**: Map, Set, Arrays; often need custom implementations

### Performance:
- **Java**: Compiled; faster for algorithms
- **JS**: Interpreted; good enough for interviews

### Testing:
- **Java**: JUnit, TestNG
- **JS**: Jest, Mocha, Jasmine
